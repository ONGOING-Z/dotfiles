# 🚀 Web UI 快速开始指南

欢迎使用 Dotfiles Web UI！这是一个 5 分钟快速入门指南。

## 📦 第一步：安装

选择你喜欢的方式：

### 方式 A：使用启动脚本（最简单）

```bash
cd webui
./start.sh
```

就这么简单！脚本会自动：
- ✅ 检查 Python 版本
- ✅ 创建虚拟环境
- ✅ 安装所有依赖
- ✅ 启动 Web 服务器

### 方式 B：使用 Docker

```bash
cd webui
docker-compose up -d
```

Docker 会自动处理所有依赖。

### 方式 C：手动安装

```bash
cd webui
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 app.py
```

## 🌐 第二步：访问界面

启动后，打开浏览器访问：

```
http://localhost:5000
```

你会看到欢迎页面！

## 🎯 第三步：5 分钟导览

### 1️⃣ 查看仪表盘（30 秒）

第一次打开就是仪表盘：
- 查看配置文件统计
- 查看各组件信息
- 点击"运行健康检查"按钮

### 2️⃣ 浏览配置文件（1 分钟）

点击左侧 "📁 文件浏览"：
1. 在搜索框输入 "zsh" 试试
2. 点击任意文件查看
3. 自动跳转到预览页面

### 3️⃣ 编辑配置（1 分钟）

在预览页面：
1. 点击"编辑"按钮
2. 修改一些内容
3. 点击"保存"
4. 自动创建备份！

### 4️⃣ 查看依赖关系（1 分钟）

点击左侧 "🔗 依赖关系"：
1. 看到漂亮的依赖关系图
2. 拖拽节点试试
3. 鼠标悬停查看详情

### 5️⃣ 创建快照（1 分钟）

点击左侧 "💾 快照管理"：
1. 输入快照名称（如 "my-first-snapshot"）
2. 点击"创建快照"
3. 在列表中看到新快照

### 6️⃣ 查看历史（30 秒）

点击左侧 "📜 操作历史"：
- 看到你刚才所有的操作记录

## 🎨 常用操作

### 切换主题

```
配置管理 → 主题下拉菜单 → 选择主题 → 保存配置
```

### 启用/禁用组件

```
配置管理 → 组件开关区域 → 切换开关 → 保存配置
```

### 搜索配置文件

```
文件浏览 → 搜索框输入关键词 → 实时过滤结果
```

### 编辑并保存文件

```
文件浏览 → 点击文件 → 实时预览 → 编辑 → 保存
```

### 创建配置快照

```
快照管理 → 输入名称 → 创建快照
```

或者点击顶部的快速创建按钮：
```
顶部右上角 → 📷 创建快照
```

### 运行健康检查

```
仪表盘 → 健康检查区域 → 运行健康检查
```

## 💡 使用技巧

### 技巧 1：键盘快捷键

虽然目前没有键盘快捷键，但你可以使用浏览器的：
- `Ctrl+F`：搜索页面内容
- `F5`：刷新页面
- `Ctrl+点击`：新标签页打开

### 技巧 2：快速导航

左侧导航栏始终可见，快速切换功能：
1. 📊 仪表盘 - 概览
2. ⚙️ 配置管理 - 设置
3. 🔗 依赖关系 - 可视化
4. 📁 文件浏览 - 浏览文件
5. 👁️ 实时预览 - 编辑文件
6. 💾 快照管理 - 备份
7. 📜 操作历史 - 历史记录

### 技巧 3：工作流建议

**每日工作流：**
```
1. 仪表盘 → 查看概况
2. 健康检查 → 确保系统正常
3. 文件浏览/预览 → 编辑配置
4. 操作历史 → 确认变更
```

**重要变更前：**
```
1. 快照管理 → 创建快照（命名清晰）
2. 配置管理 → 修改设置
3. 依赖关系 → 确认影响范围
4. 操作历史 → 验证变更
```

## 🐛 遇到问题？

### 端口被占用

```bash
# 查看占用端口的进程
lsof -i :5000

# 或使用其他端口
python3 app.py --port 8080
```

### 无法访问

1. 确认服务器正在运行
2. 检查防火墙设置
3. 尝试 `http://127.0.0.1:5000`

### 文件编辑保存失败

1. 检查文件权限
2. 确认磁盘空间充足
3. 查看浏览器控制台错误

### 依赖关系图不显示

1. 刷新页面
2. 点击"刷新图表"
3. 检查 `install.conf.yaml` 文件
