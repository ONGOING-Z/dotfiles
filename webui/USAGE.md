# Dotfiles Web UI 使用指南

## 🎯 快速开始

### 方法 1：使用启动脚本（推荐）

这是最简单的方式，脚本会自动处理依赖安装：

```bash
cd webui
./start.sh
```

启动后，打开浏览器访问 [http://localhost:5000](http://localhost:5000)

### 方法 2：Docker 运行

如果你喜欢使用 Docker：

```bash
cd webui

# 使用 docker-compose（推荐）
docker-compose up -d

# 或使用 docker build
docker build -t dotfiles-webui .
docker run -p 5000:5000 \
  -v $(pwd)/..:/dotfiles:ro \
  -v ~/.dotfiles:/root/.dotfiles \
  dotfiles-webui
```

### 方法 3：手动运行

如果你想完全控制：

```bash
cd webui

# 创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 运行应用
python3 app.py
```

## 📚 功能详解

### 1️⃣ 仪表盘（Dashboard）

仪表盘是你的控制中心：

**统计信息**
- 📁 配置文件总数
- 💾 总文件大小
- 🕐 最后修改时间
- 📷 快照数量

**组件统计**
- 查看每个组件（zsh、tmux、vim 等）的详细信息
- 文件数量和占用空间

**健康检查**
- 一键运行系统健康检查
- 查看检查结果和建议

#### 示例操作

```
1. 点击"运行健康检查"按钮
2. 等待检查完成
3. 查看结果，了解系统状态
```

### 2️⃣ 配置管理（Configuration）

图形化配置编辑器，告别手动编辑 JSON：

**基本偏好设置**
- Shell 选择（Zsh/Bash）
- 主题切换（Dracula/Nord 等）

**组件开关**
- ✅ 启用/禁用 Homebrew
- ✅ 启用/禁用 Tmux
- ✅ 启用/禁用 Vim
- ✅ 启用/禁用 Git
- 等等...

**保存配置**
- 点击"保存配置"按钮
- 配置保存到 `~/.dotfiles/install-config.json`
- 自动记录到操作历史

#### 示例：切换主题

```
1. 进入"配置管理"页面
2. 在"主题"下拉菜单中选择 "nord"
3. 点击"保存配置"
4. 配置立即生效
```

### 3️⃣ 依赖关系图（Dependencies）

这是 Web UI 的核心功能之一，类似 Heimdall 的可视化效果：

**图表说明**
- 🔵 **蓝色节点**：源文件（仓库中的配置文件）
- 🟢 **绿色节点**：目标文件（家目录中的符号链接）
- ➡️ **箭头**：链接方向（源 → 目标）

**交互功能**
- 🖱️ 拖拽节点调整位置
- 🔍 悬停查看完整文件路径
- 🔄 点击"刷新图表"更新数据

**使用场景**
- 理解配置文件的链接关系
- 诊断符号链接问题
- 可视化配置结构

#### 示例：查看 .zshrc 的链接

```
1. 进入"依赖关系"页面
2. 找到 "zshrc" 节点（蓝色）
3. 找到 ".zshrc" 节点（绿色）
4. 观察它们之间的箭头连接
5. 悬停查看完整路径
```

### 4️⃣ 文件浏览（Files）

浏览所有配置文件：

**功能特性**
- 📋 列出所有配置文件
- 🔍 实时搜索过滤
- 📊 显示文件大小和修改时间
- 🎯 点击文件进入预览

**文件信息**
- 文件名和图标
- 相对路径
- 文件大小
- 最后修改时间

#### 示例：查找 tmux 配置

```
1. 进入"文件浏览"页面
2. 在搜索框输入 "tmux"
3. 查看过滤后的文件列表
4. 点击 "tmux.conf" 进入预览
```

### 5️⃣ 实时预览（Preview）

在线查看和编辑配置文件：

**查看模式**
- 语法高亮显示
- 保留原始格式
- 显示文件元信息

**编辑模式**
- 在线编辑器
- 实时保存
- 自动创建备份

**安全保障**
- 编辑前自动备份
- 备份文件名：`<原文件名>.backup`
- 可以随时恢复

#### 示例：编辑 .zshrc

```
1. 从文件浏览选择 .zshrc
2. 点击"编辑"按钮
3. 修改内容
4. 点击"保存"
5. 系统自动创建 .zshrc.backup
```

### 6️⃣ 快照管理（Snapshots）

创建和管理配置快照：

**创建快照**
- 输入快照名称（可选）
- 点击"创建快照"
- 快照包含所有重要配置文件

**查看快照**
- 快照列表显示所有历史快照
- 显示大小和创建时间
- 自动保留最近 5 个快照

**快照存储**
- 位置：`~/.dotfiles/backups/`
- 格式：`<名称>_<时间戳>.tar.gz`
- 自动压缩节省空间

#### 示例：重要更改前创建快照

```
1. 进入"快照管理"页面
2. 输入快照名称："before-theme-change"
3. 点击"创建快照"
4. 等待创建完成
5. 在列表中看到新快照
```

### 7️⃣ 操作历史（History）

查看所有配置变更：

**历史记录包含**
- 配置保存操作
- 快照创建
- 文件修改
- Web UI 操作

**显示信息**
- 操作时间
- 操作类型
- 详细描述

**使用场景**
- 追踪配置变更
- 审计操作记录
- 诊断问题

## 🎨 使用技巧

```

2. 配置管理 → 调整设置
3. 快照管理 → 创建快照
```

```
1. 快照管理 → 创建快照（before-theme）
2. 配置管理 → 切换主题
3. 实时预览 → 检查配置文件
4. 操作历史 → 确认变更
```

### 技巧 3：诊断问题

```
1. 仪表盘 → 运行健康检查
2. 依赖关系 → 查看链接状态
3. 文件浏览 → 检查配置文件
4. 操作历史 → 追溯最近变更
```

### 技巧 4：批量编辑配置

```
1. 快照管理 → 创建快照（保护）
2. 文件浏览 → 搜索相关文件
3. 实时预览 → 逐个编辑
4. 操作历史 → 确认所有变更
```

## 🔧 高级功能

### API 集成

Web UI 提供完整的 REST API，可以与其他工具集成：

```bash
# 获取配置
curl http://localhost:5000/api/config

# 创建快照
curl -X POST http://localhost:5000/api/snapshots \
  -H "Content-Type: application/json" \
  -d '{"name": "my-snapshot"}'

# 获取统计信息
curl http://localhost:5000/api/stats
```

### 自定义端口

```bash
# 修改 app.py 最后一行
app.run(host='0.0.0.0', port=8080, debug=True)

# 或使用环境变量
export FLASK_PORT=8080
python3 app.py
```

### 远程访问（谨慎使用）

```bash
# 默认只监听本地，如需远程访问：
# 修改 app.py
app.run(host='0.0.0.0', port=5000, debug=False)

# 建议使用 SSH 隧道
ssh -L 5000:localhost:5000 user@remote-host
```

## 🐛 常见问题

### Q: 端口被占用怎么办？

```bash
# 查找占用进程
lsof -i :5000

# 或使用其他端口
python3 app.py --port 8080
```

### Q: 无法保存文件？

检查文件权限：
```bash
ls -la ~/.zshrc
chmod 644 ~/.zshrc
```

### Q: 依赖关系图不显示？

1. 刷新页面
2. 点击"刷新图表"按钮
3. 检查浏览器控制台错误

### Q: 快照创建失败？

检查配置目录权限：
```bash
ls -la ~/.dotfiles
mkdir -p ~/.dotfiles/backups
```

## 📊 性能优化

### 大量配置文件

如果配置文件很多（>1000 个）：

1. 使用搜索功能过滤
2. 避免频繁刷新依赖关系图
3. 考虑分页显示

### 大文件编辑

文件大小限制为 1MB：

1. 大文件请使用命令行编辑器
2. 或分割成多个小文件
3. Web UI 主要用于查看和小改动

## 🔐 安全建议

1. **仅本地访问**：默认只监听 127.0.0.1
2. **文件备份**：编辑前自动备份
3. **权限控制**：保持合理的文件权限
4. **定期快照**：重要操作前创建快照
