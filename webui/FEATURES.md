# Web UI 功能特性详解

## 🎯 核心功能

### 1. 仪表盘（Dashboard）

仪表盘是你的配置管理控制中心，提供系统全景视图：

#### 统计卡片
- **配置文件数量**：实时统计所有配置文件
- **总文件大小**：显示配置占用的磁盘空间
- **最后修改时间**：追踪最近的配置变更
- **快照数量**：显示已创建的备份快照数

#### 组件统计
按组件分类显示详细信息：
- Zsh 配置（文件数、大小）
- Tmux 配置（文件数、大小）
- Vim/Neovim 配置（文件数、大小）
- Git 配置（文件数、大小）
- 其他配置组件

#### 健康检查
- 一键运行系统健康检查脚本
- 实时显示检查结果
- 高亮显示潜在问题
- 提供修复建议

### 2. 配置管理（Configuration）

图形化配置编辑器，无需手动编辑 JSON 文件：

#### 基本偏好设置
- **Shell 选择**：Zsh 或 Bash
- **主题选择**：从可用主题中选择（Dracula、Nord 等）
- **插件配置**：启用/禁用特定插件

#### 组件开关
使用直观的切换开关控制各个组件：
- Dotfiles 符号链接
- Homebrew 包管理
- Zsh 配置
- Tmux 配置
- Vim 配置
- Git 配置
- 其他自定义组件

#### 配置持久化
- 自动保存到 `~/.dotfiles/install-config.json`
- 实时验证配置有效性
- 记录所有配置变更
- 支持配置导入/导出

### 3. 依赖关系可视化（Dependencies）

这是 Web UI 的亮点功能，类似 Heimdall 的可视化效果：

#### 交互式图表
- **节点**：
  - 蓝色节点：源文件（仓库中的配置文件）
  - 绿色节点：目标文件（家目录中的符号链接）
- **边**：表示链接方向（源 → 目标）
- **布局**：分层布局，自动优化节点位置

#### 交互功能
- **拖拽**：拖动节点调整视图
- **缩放**：滚轮缩放查看细节
- **悬停**：显示完整文件路径
- **点击**：选中节点查看详情

#### 可视化优势
- 直观了解配置文件结构
- 快速定位符号链接关系
- 诊断链接问题
- 理解配置依赖

### 4. 文件浏览（Files）

浏览和管理所有配置文件：

#### 文件列表
- 显示所有配置文件
- 按组件分类显示
- 显示文件元信息（大小、修改时间）
- 智能图标识别

#### 搜索功能
- 实时搜索过滤
- 支持文件名搜索
- 支持路径搜索
- 模糊匹配

#### 文件信息
- 文件名和扩展名
- 相对路径
- 文件大小（格式化显示）
- 最后修改时间

### 5. 实时预览（Preview）

在线查看和编辑配置文件：

#### 查看模式
- **语法高亮**：根据文件类型高亮显示
- **保留格式**：保持原始缩进和换行
- **元信息显示**：文件路径、大小、修改时间
- **代码字体**：使用等宽字体显示

#### 编辑模式
- **在线编辑器**：内置代码编辑器
- **实时保存**：即时保存修改
- **自动备份**：编辑前自动创建备份
- **撤销保护**：保留备份文件以便恢复

#### 安全特性
- 文件大小限制（1MB）
- 自动创建 `.backup` 文件
- 验证文件权限
- 防止误操作

### 6. 快照管理（Snapshots）

创建和管理配置快照：

#### 快照功能
- **创建快照**：
  - 自定义快照名称
  - 包含所有重要配置文件
  - 自动压缩存储
  - 记录创建时间

- **快照列表**：
  - 显示所有历史快照
  - 按时间倒序排列
  - 显示快照大小
  - 快速恢复功能（未来支持）

#### 自动管理
- 保留最近 5 个快照
- 自动清理旧快照
- 压缩存储节省空间
- 时间戳命名防止冲突

#### 存储位置
- 目录：`~/.dotfiles/backups/`
- 格式：`<名称>_<时间戳>.tar.gz`
- 结构：tar.gz 压缩包

### 7. 操作历史（History）

追踪所有配置变更：

#### 历史记录
- 配置保存操作
- 快照创建事件
- 文件修改记录
- Web UI 操作日志

#### 显示信息
- 操作时间（精确到秒）
- 操作类型
- 详细描述
- 用户标识

#### 使用场景
- 审计配置变更
- 诊断问题根源
- 回溯历史操作
- 团队协作追踪

### API 设计

#### RESTful 接口
```
GET  /api/config          # 获取配置
POST /api/config          # 保存配置
GET  /api/dependencies    # 获取依赖图
GET  /api/files           # 列出文件
GET  /api/files/<path>    # 获取文件内容
PUT  /api/files/<path>    # 保存文件
GET  /api/snapshots       # 列出快照
POST /api/snapshots       # 创建快照
GET  /api/history         # 获取历史
GET  /api/stats           # 获取统计
GET  /api/themes          # 列出主题
GET  /api/health          # 健康检查
```

## 💡 使用建议

### 最佳实践
1. 定期创建快照
2. 重要变更前备份
3. 使用操作历史追踪
4. 利用依赖图理解结构

### 性能建议
1. 大文件用命令行编辑
2. 避免频繁刷新依赖图
3. 定期清理旧快照
4. 使用搜索功能过滤

### 安全建议
1. 仅本地访问
2. 使用 SSH 隧道远程访问
3. 定期备份配置
4. 保持软件更新
