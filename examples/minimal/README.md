# 最小化配置示例

适合只需要基础配置的用户，包含最少的依赖和配置。

## 特点

- ✅ 基础 Shell 配置
- ✅ 简单的 Git 别名
- ✅ 最小的 Vim 配置
- ❌ 无插件管理器
- ❌ 无主题
- ❌ 无额外工具

## 包含内容

```
.bashrc        # 基础 Bash 配置
.vimrc         # 最小 Vim 配置
.gitconfig     # 基础 Git 配置
```

## 安装

```bash
cd ~/dotfiles
./install --minimal
```

## 配置说明

### Shell 配置
- 基础提示符
- 常用别名（ll, la, ..）
- 历史记录设置

### Vim 配置
- 语法高亮
- 行号显示
- 基础缩进设置

### Git 配置
- 用户信息
- 常用别名
- 颜色输出
